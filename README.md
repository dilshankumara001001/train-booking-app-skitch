# 🚆 Train Ticket Booking & Management System

A comprehensive and user-friendly mobile application designed for seamless train ticket booking, digital wallet management, and contactless travel. This application provides an intuitive user interface for searching trains, selecting seats, managing payments, and generating e-tickets with QR codes.

## ✨ Key Features

*   **🔐 User Authentication & Profile Management:**
    *   Secure login and personalized user dashboard.
    *   Manage user profiles (Name, Password, Email, Location).
    *   Support for multiple passenger profiles for quick booking.
*   **🏠 Home & Search:**
    *   Search destinations and view upcoming train schedules.
    *   Quick access to order train food, round trip tickets, and specific routes (e.g., Apex square to Proxima).
*   **💳 Digital Wallet Integration:**
    *   Check wallet balance (e.g., $500.56) and coin balance.
    *   Add and manage payment methods (Visa, Mastercard, BOC).
    *   View detailed transaction history (food orders, ticket purchases).
*   **💺 Smart Seat Selection:**
    *   Interactive carriage and seat selection (Carriage 01, 02, 03, etc.).
    *   Real-time UI updates showing Selected, Available, and Occupied seats.
    *   Visual seat map (e.g., A1, B2, C3, D4).
*   **🎫 E-Ticket Generation:**
    *   Generates a scannable QR code for easy boarding.
    *   Displays comprehensive journey details:
        *   Booking ID (e.g., Uzmy123)
        *   Route (e.g., Apex square to Proxima)
        *   Time & Date
        *   Passenger Details (Name, ID number, Passenger type, Seat number, Carriage)
*   **🧭 Intuitive Navigation:**
    *   Bottom navigation bar for easy access to Home, My Wallet, My Ticket, and Account.
